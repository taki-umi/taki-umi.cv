2025/12 ~ 参画中
所属株式会社マルチプル（正社員）
チーム規模2 人
言語・FWNext.js / TypeScript
インフラVercel / Supabase / Clerk / AWS
外部連携ReCore（店舗POS）
業界トレーディングカード・卸売事業
役割販売ECサイトの立ち上げ（要件整理〜設計〜開発〜リリース）、買取サイトの機能改修・SEO対策、店舗業務のシステム化

プロダクト概要

自社カード郵送買取サイトの運営・機能改修、および自社カード販売ECサイトの新規立ち上げ。

業務内容

1. 自社カード販売ECサイトを1ヶ月（2026/07 ~ 2026/08）で立ち上げ、リリースまで完遂

  • 事業部・店舗の業務関係者と直接やり取りしながら要件を整理し、リリースに必要な最低限の機能を見極めてスコープを確定させた
  • ReCoreなどの外部POSと連携し、店舗在庫・商品マスタをサイト側に取り込む仕組みを構築した
  • Next.js / TypeScript による実装からVercelへのデプロイ、リリース後の運用まで一貫して担当した

2. 買取サイトの運営・改善

  • 自社カード郵送買取サイトの機能改修・SEO対策・事業部からの要望改善を継続的に実施している

3. 店舗業務のシステム化

  • 会社の関連店舗業務のシステム化にも注力し、店舗の買取表自動生成などの業務改善を行っている
